From the Docs add-on to the Chrome extension

Optional · shortcuts and a field on the document sheet

You can already calculate and insert using Extensions → MathDocs CAS → Open editor. Add the Chrome extension if you want to open the field directly with a keyboard shortcut.

  1. Use Chrome on your computer. Open the Chrome profile you use for Google Docs.
  2. Install MathDocs CAS from the Chrome Web Store once it is published. Check the name and publisher: Ahmed Abdirashid Ahmed. Choose Add to Chrome → Add extension. Check publication status if you cannot find it.
  3. Optionally pin the MathDocs icon. Open the extensions menu by the address bar and select the pin next to MathDocs CAS.
  4. Reload your Google document. Click in the document text where the formula belongs.
  5. Open the math field. Windows: Ctrl + M. Mac: Option + M. You can also use the MathDocs icon or the ∑ button in the document.

Ready: a MathDocs field appears on the document sheet. Continue with your first calculation.

From the Chrome extension to the Docs add-on

Required to save formulas from the Chrome field

The Chrome extension provides the field and shortcuts. The Docs add-on gives MathDocs access to insert and edit formulas in the document you are working on.

  1. Open a Google document you can edit. Use the Google account that should have MathDocs installed.
  2. Choose Extensions → Add-ons → Get add-ons. Find MathDocs CAS in Google Workspace Marketplace once it is published. Check the publisher, Ahmed Abdirashid Ahmed. Check publication status if it is missing.
  3. Choose Install → Continue. Select the same Google account as your document, read the permissions and authorize in Google’s dialog.
  4. Reload the document and open the editor once. Choose Extensions → MathDocs CAS → Open editor. Complete any Google authorization prompt.
  5. Choose how to work. Use the menu editor, or close it, click in the document text and open the Chrome field with Ctrl + M on Windows or Option + M on Mac.

Ready: the menu editor opens and a saved result appears in the document. The Chrome shortcut works when the extension is also installed in the active Chrome profile.

Your first calculation

  1. Type 1/2 and press Space. Then type +1/3 and press Space again.
  2. Press Enter. The result is 5/6, displayed as a fraction on a new line in the editor.
  3. Press Ctrl + Enter on Windows or Cmd + Enter on Mac. Wait for the formula and result to be saved in the document; saving requires a Google connection.
  4. Select the inserted formula image and open MathDocs from the menu again. Change 1/3 to 1/6, calculate and save. The result should now be 2/3.

If something is missing

I have the Chrome extension, but cannot save

Follow the Docs guide and open the menu editor once using the same account as the document. You need editing access. If a save cannot be confirmed, check the document before retrying and keep your draft.

MathDocs is missing from the Docs menu

Reload the document and check your Google account. Look under Extensions → Add-ons → Manage add-ons. If you are editing a Word file directly, convert it to Google Docs format to use Editor add-ons.

The shortcut does not open the field

Use Chrome on a computer, check that MathDocs is enabled in the current Chrome profile and reload the document after installation. Click in the document text. Also try the ∑ button or the MathDocs icon.

My school or workplace blocks installation

Ask your administrator to allow MathDocs CAS in both Google Workspace Marketplace and the Chrome Web Store if you want both components. The two stores can have different administrator policies.

Do I need to copy code into Apps Script?

Regular users install the published add-on from Marketplace. Manually copying Apps Script files is for development and separately arranged test installations. This guide requires no code copying.

Do my collaborators need MathDocs?

Anyone with document access can see and print saved formula images. Editing their mathematical source requires the Docs add-on. The Chrome extension is optional. Formulas are images with editing data, not native Google equation fields.
