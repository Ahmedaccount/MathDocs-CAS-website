Setup & support

MathDocs has two components. The Editor add-on provides document insertion and an editor in Google Docs. The optional Chrome extension adds an editor on the document sheet and keyboard shortcuts. The extension needs the MathDocs document adapter for insertion.

Using the Editor add-on

  1. After installation, open a Google document and place the text cursor where the formula belongs.
  2. Choose Extensions → MathDocs CAS → Open editor and authorize access to the current document and its user interface.
  3. Type 1/2, press Space, type +1/3 and press Enter. The result is 5/6.
  4. Press Ctrl+Enter on Windows or Cmd+Enter on Mac to insert the formula and result. Saving needs a Google connection.
  5. Select an existing MathDocs image and open the editor again to edit its source.

Chrome shortcuts

Windows: Ctrl+M opens the field and calculates inside it. Mac: Option+M opens or focuses; Option+S calculates. Enter calculates on both. Alt+P / Option+P plots. Shortcuts apply inside Docs and the editor.

Sharing and recovery

Collaborators can see images without MathDocs. Source editing requires the editor. Values used in a saved calculation are included with it, even when they originated in private variables. Copies or exports may remove source metadata. If a save fails, keep the draft and check the document before retrying to avoid duplicates.
