How MathDocs works

A visual editor

Type mathematics, format fractions and calculate with Enter. Define variables and explore function plots.

Made for documents

Insert formulas as compact images with editable source. Everyone can read and print them. Mathematical editing uses MathDocs; saved images are not native Google equation fields.

Free to use

No ads or analytics. The visual editor calculates locally; Google Apps Script handles document access and saving.

Installation

The Google Docs Editor add-on works from the Extensions menu. An optional Chrome extension adds shortcuts and a field on the document sheet. Public store installation will become available after publication; neither listing is currently approved.
