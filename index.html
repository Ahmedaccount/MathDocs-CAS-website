A FEW USEFUL DETAILS

Before you get started.

Is MathDocs free?

Yes. MathDocs is free during this preview, and the browser demo needs no payment or account. Any future paid plans will be announced clearly before they apply.

Do I need both installations?

The Docs add-on works on its own from the Extensions menu. The optional Chrome extension adds the editor on the document page and keyboard shortcuts. It does not replace the add-on’s document access.

Can everyone read my formulas?

Yes. Saved formulas are images, so other people can view and print the document without installing MathDocs. Editing the mathematical source needs MathDocs. These are not native Google equation objects; exporting or re-encoding an image can remove its source metadata.

Where are calculations processed?

The visual editor calculates in a local browser worker. Google Apps Script handles the current-document connection and saving. The browser demo stays in this browser and does not connect to your documents. There are no advertising or analytics trackers.

Why can’t I install it from the stores yet?

The Docs add-on has been submitted for Google review. The Chrome companion is not publicly available yet. Review is not approval. Verified installation links will be added to this website when the listings are public.

How do I report something that feels wrong?

Contact Aaccount using the link below. An example expression, what you expected, and what actually happened are useful starting points. The project is actively being improved.
